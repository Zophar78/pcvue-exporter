01 / Overview

From supervision to observability.

The exporter reads configured values from PCVue and exposes a Prometheus /metrics endpoint. Bring industrial process measurements into existing dashboards and monitoring workflows.

Real-time variables

Track selected PCVue values alongside the rest of your infrastructure and application metrics.

Alarm aggregates

Monitor counts of active and unacknowledged alarms and the age of the oldest active alarm.

Alerts and dashboards

Build Grafana dashboards and define Prometheus alerts from the metrics that matter to your operation.

02 / Example output

03 / Get started

Built for your stack.

Run the Go exporter locally or with Docker. Configure direct PCVue authentication or connect through an API gateway using OAuth2.

Requires access to a properly licensed PCVue WST REST API. This is an independent open-source project and is not affiliated with PcVue Solutions.
